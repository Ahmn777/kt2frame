# КТ2 — Интеграция с Backend API

Готовый учебный проект для практикума: React + TypeScript, React Router, Zustand, Axios interceptors, JWT-токен и PrivateRoute. В комплекте есть локальный mock backend, чтобы приложение запускалось и проверялось без API преподавателя.

## 1. Что нужно установить

- Node.js LTS (желательно 20 или 22)
- VS Code

## 2. Как запустить — просто по шагам

1. Распакуйте архив в удобную папку.
2. Откройте папку `KT2_Integration_API` в VS Code.
3. Откройте Terminal → New Terminal.
4. Выполните одну команду:

   ```bash
   npm run install:all
   ```

5. Когда установка закончится, выполните:

   ```bash
   npm run dev
   ```

6. Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

Оба сервера запускаются одной командой: frontend на порту 5173 и учебный API на порту 4000. Чтобы остановить их, нажмите `Ctrl+C` в терминале.

## 3. Данные для входа

- Email: `demo@example.com`
- Пароль: `password123`

Это только тестовые данные локального mock backend.

## 4. Как проверить шесть сценариев

1. **Без токена:** нажмите «Выйти» или удалите `token` в DevTools → Application → Local Storage, затем откройте `/dashboard`. Должно перенаправить на `/login`.
2. **Успешный вход:** введите тестовые email и пароль. Откроется защищённая страница.
3. **Токен в запросе:** на странице нажмите «Обновить данные». Сервер вернёт профиль; Axios добавляет `Authorization: Bearer ...` автоматически.
4. **F5:** обновите защищённую страницу. Вход должен сохраниться, потому что токен хранится в `localStorage`.
5. **Выход:** нажмите «Выйти», затем снова откройте `/dashboard`. Доступ будет закрыт.
6. **Повторная попытка и переход на страницу входа:** после успешного входа откройте `/login` — приложение вернёт вас на `/dashboard`. Выйдите и попробуйте неверный пароль — увидите сообщение об ошибке.

## 5. Если преподаватель выдаёт другой API

Откройте `frontend/.env` и укажите адрес API:

```env
VITE_API_URL=https://АДРЕС-API-ОТ-ПРЕПОДАВАТЕЛЯ
```

После изменения `.env` перезапустите `npm run dev`. Учтите: адрес сам по себе не гарантирует совместимость — пути и формат ответа у API преподавателя могут отличаться. В текущем учебном проекте используются:

- `POST /auth/login` с JSON `{ "email": "...", "password": "..." }`, ответ должен содержать `token` или `accessToken`;
- `GET /api/profile` — защищённые данные;
- заголовок `Authorization: Bearer <token>`.

Если преподаватель дал другие endpoint'ы или другой формат ответа, адаптируйте `frontend/src/store/authStore.ts` и `frontend/src/store/dataStore.ts`. После изменения `.env` обязательно перезапустите Vite.

## 6. Где что находится

- `frontend/src/api/client.ts` — axios.create и оба interceptor'а.
- `frontend/src/store/authStore.ts` — login, logout и состояние авторизации в Zustand.
- `frontend/src/store/dataStore.ts` — запрос защищённых данных.
- `frontend/src/App.tsx` — маршруты и `PrivateRoute`.
- `frontend/src/pages/LoginPage.tsx` — форма входа.
- `frontend/src/pages/DashboardPage.tsx` — защищённая страница.
- `mock-backend/server.js` — локальный API для проверки.

## 7. Проверка сборки

Из корневой папки можно выполнить `npm run build`. Если ошибок нет, production-сборка frontend завершится успешно.
